# 契约收窄 Skill

## 委派规则

1. **契约下传**：每次委派必须在子会话 prompt 中内嵌一份"契约摘录"，包含：
   - 全部适用的 C 条款（红线原样下传，永不删减）；
   - 该子任务专属的 G-4 验收清单（从父任务清单中切出，可检验）；
   - 相关 M/P 条款摘录。
2. **只收不放**：子会话的权限/预算/范围 ≤ 父会话。明确写出收窄项，例如：
   - 预算：父预算的一个明确子额度；
   - 范围：仅限指定目录/仓库；
   - 上奏路径：大臣遇 P-2 情形不得直接决定，上报宰相；宰相判断是否需再上奏皇帝。
3. **递归**：大臣再委派下属时适用同样规则（契约再收窄）。若平台不支持再递归，
   由宰相代为拆分并平行委派。
4. **验收**：子会话完成后，宰相必须逐项核对其 G-4 清单（能跑的验证必须跑），
   不合格打回重做（最多 2 次，仍不合格则上奏）。
5. **留痕**：每次委派与验收结果在 decree_log 记"里程碑"一条。

## 委派 prompt 模板

```
【契约摘录 — 你必须遵守】
红线（违反即停并上报）：<C 条款原文>
你的验收清单：<可检验产物列表>
范围与预算：<收窄后的边界>
遇到以下情况停止并上报，不得自主决定：<P-2 摘录>
【任务】<任务描述>
```
